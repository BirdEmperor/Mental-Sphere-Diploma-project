# Інструкція з розгортання, запуску та тестування інформаційної системи "Ментальна куля"

Документ призначений для швидкої підготовки проєкту до перегляду, рецензування та демонстрації. Нижче залишено тільки обов'язкові дії, контрольні точки і очікувані дані.

| Параметр | Значення |
|---|---|
| Unity-проєкт | `https://github.com/BirdEmperor/Mental-Sphere-Diploma-project` |
| Сервер | `https://github.com/BirdEmperor/mental-sphere-server` |
| Unity | `6000.4.5f1` |
| Цільова сцена | `Assets/Scenes/Main_MVP_Backup.unity` |
| Публічний API | `https://mental-sphere-server.onrender.com` |
| Цільовий пристрій | Meta Quest / Quest 2 / Quest 3 / Quest 3S через OpenXR |

## 1. Обов'язково підготувати середовище

1. Скачати Unity-репозиторій з GitHub.
2. Не додавати папку `Library` у репозиторій і не очікувати її в архіві: Unity створить її під час першого імпорту.
3. Перевірити вільне місце на диску: для першого відкриття бажано мати не менше 20-30 ГБ.
4. Встановити Unity `6000.4.5f1` через Unity Hub.
5. Додати модулі `Android Build Support`, `Android SDK & NDK Tools`, `OpenJDK`.
6. Перевірити пакети `OpenXR Plugin`, `XR Interaction Toolkit`, `Universal Render Pipeline`.
7. Підготувати шолом Meta Quest: увімкнути Developer Mode, дозволити USB debugging, під'єднати через Quest Link, Air Link або USB-C.
8. Переконатися, що комп'ютер і шолом мають доступ до Інтернету для звернення до Render API.

## 2. Обов'язково перевірити сервер Render

1. Врахувати, що перший запит може тривати довше через cold start Render.
2. Перевірити `/health`.
3. Перевірити генерацію для сфер `blue`, `green`, `yellow`.
4. Перевірити повний цикл телеметрії: старт сесії, подія сесії, завершення сесії.

```powershell
$base = "https://mental-sphere-server.onrender.com"
Invoke-WebRequest -Uri "$base/health" -UseBasicParsing
Invoke-WebRequest -Uri "$base/generate/blue?user_id=reviewer" -UseBasicParsing
Invoke-WebRequest -Uri "$base/generate/green?user_id=reviewer" -UseBasicParsing
Invoke-WebRequest -Uri "$base/generate/yellow?user_id=reviewer" -UseBasicParsing
```

### Очікувані дані API

| Маршрут | Що перевірити | Очікувані дані |
|---|---|---|
| `GET /health` | Стан сервера | JSON містить `status: ok` і поле `time` |
| `GET /generate/blue` | Синя сфера | `sphereColor: blue`, `profileId`, `seed`, `terrain`, `objects`, параметри озера та води |
| `GET /generate/green` | Зелена сфера | `sphereColor: green`, лісовий профіль, поля `treeCount`, `bushCount`, `branchCount` |
| `GET /generate/yellow` | Жовта сфера | `sphereColor: yellow`, польовий профіль, багато квітів, відкритий простір |
| `POST /sessions/start` | Початок телеметрії | `sessionId`, `status: started` |
| `POST /sessions/{id}/event` | Подія взаємодії | `status: event_saved`, `eventId` |
| `POST /sessions/{id}/finish` | Завершення сесії | `status: session_finished`, той самий `sessionId` |

Мінімальний приклад циклу телеметрії:

```powershell
$body = '{"userId":"reviewer","sphereColor":"blue","profileId":"lake_blue","seed":12345}'
$session = Invoke-RestMethod -Method Post -Uri "$base/sessions/start" -ContentType "application/json" -Body $body
Invoke-RestMethod -Method Post -Uri "$base/sessions/$($session.sessionId)/event" -ContentType "application/json" -Body '{"eventType":"sphere_selected","payloadJson":"{}"}'
Invoke-RestMethod -Method Post -Uri "$base/sessions/$($session.sessionId)/finish" -ContentType "application/json" -Body '{"durationSeconds":60,"averageFps":72,"interactionCount":1,"status":"completed"}'
```

## 3. Обов'язково запустити Unity Editor

1. Відкрити проєкт у Unity Hub.
2. Дочекатися завершення першого імпорту.
3. Відкрити сцену `Assets/Scenes/Main_MVP_Backup.unity`.
4. У `File -> Build Settings` переконатися, що активною сценою збірки є `Main_MVP_Backup`. `TestingScene` не використовувати.
5. У сцені перевірити, що `LocationApiClient` звертається до `https://mental-sphere-server.onrender.com`.
6. Запустити Play Mode.
7. У hub активувати синю, зелену і жовту сфери.
8. Після генерації кожної локації перевірити повернення в hub через сферу повернення. Для запасної перевірки можна використати клавішу `F`.

### Очікувані результати в Unity

| Дія | Очікуваний результат |
|---|---|
| Запуск `Main_MVP_Backup` | Видимий hub з трьома сферами вибору |
| Синя сфера | Генерується озерна локація з водою, берегом, рослинністю і камінням |
| Зелена сфера | Генерується щільніша лісова локація з деревами, кущами і гілками |
| Жовта сфера | Генерується відкрита польова локація з великою кількістю квітів |
| Сфера повернення | Розміщена поряд із користувачем і повертає до hub |
| Телеметрія | У консолі немає помилок API, сервер приймає старт, події і завершення сесії |

## 4. Перевірити збірку APK

1. У `Build Settings` вибрати платформу Android.
2. У списку сцен залишити `Assets/Scenes/Main_MVP_Backup.unity`.
3. У `XR Plug-in Management` перевірити OpenXR для Android.
4. У `OpenXR` перевірити профілі контролерів Meta Quest.
5. У `Player Settings` перевірити дозвіл на доступ до Інтернету.
6. Для Quest-збірки використовувати `IL2CPP` і `ARM64`.
7. Натиснути `Build And Run` або зібрати APK і встановити його на шолом.
8. На шоломі повторити сценарій: hub -> синя сфера -> повернення -> зелена сфера -> повернення -> жовта сфера -> повернення.
